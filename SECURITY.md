# Security Policy

## Reporting a vulnerability
Report privately through GitHub: open the Security tab of this repository and click "Report a vulnerability".
Please do not open public issues, pull requests or posts about a vulnerability before it is fixed.

## Scope
The contracts listed in contracts/README.md and the site https://sonevibe.github.io/Lending/.

## How we review
Every change goes through an internal security review and source verification on Sourcify before release.

## Stay safe
SoneVibe never sends the first DM and never asks for private keys or seed phrases.
