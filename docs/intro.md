# SoneVibe

BNB Chain (chain ID 56) is the main chain. Arbitrum One (chain ID 42161) also runs the DEX.

Swap and liquidity pools are live. Lending is coming soon on BNB Chain.

Yields and APR are variable, not guaranteed.

Contract addresses for the live DEX are in `networks.json`, `pools.json`, and the Docs page. The connected wallet signs every transaction.
