Temporary Astar NFT listing cancel

Owner/seller helper to cancel listings on the SoneVibe Astar NFT market when the indexer missed the blocks. Reads ItemListed logs over RPC, checks listings(nft, tokenId), then calls cancelListing only. No approve / setApprovalForAll.

Temporary / unlinked page. Chain id 592 only. Proxy 0x691459a1D00e6fa2BD39502FF58BfDE8a804940c. After cancel, the NFT always returns to the listing seller (not necessarily the connected wallet).
